# 玩机工具箱

免 root 的 Android 玩机工具箱。全部特权操作通过 **Shizuku**（ADB 级权限）和 **Dhizuku**（设备所有者委托）实现，**不需要解锁 Bootloader，不需要刷机，不需要 Root**。

## 一句话

装上 Shizuku，就能在一台完全原厂的手机上做大部分需要 Root 才能做的事。

## 能做什么

**应用管理**
- 免 root 卸载系统应用（可恢复）、冻结/解冻、隐藏、停用/启用、强行停止、清除数据
- 批量多选操作，支持首字母 / 最后更新 / 首次安装三种排序
- 应用详情页：大小占用（本体/数据/缓存）、版本、包名、Activity 列表直启
- APK 提取备份到本地

**权限控制**
- 危险权限一键授予/撤销
- 三态管控：允许 / 仅开屏时允许 / 不允许（治摇一摇、后台偷录）
- 权限与 AppOps 合并展示，可修改的排前面，权限名全中文

**系统调参**
- 动画速度、指针速度、熄屏时间（预设 + 自定义）、屏幕亮度、自动旋转
- 分辨率 / DPI 修改（可一键恢复）
- 强制暗色模式、显示触摸、指针位置、布局边界

**设备能力**
- 电量模拟、省电模式、充电常亮
- 一键截屏、重启 / Recovery / Bootloader / 关机
- AB 插槽查看
- 伪装短信记录（仅供设备调试）

**Dhizuku 设备所有者**（需 Android 13+）
- 禁用相机、禁止截屏、全局静音、立即锁屏
- 隐藏应用、阻止卸载、禁用锁屏、隐藏状态栏、全局代理

**其他**
- 自定义 Shell 命令 + 收藏夹
- 崩溃日志自动记录，重进即弹窗可复制

## 使用前提

1. 安装 [Shizuku](https://shizuku.rikka.app/) 并启动服务（Android 11+ 可用无线调试启动，无需电脑）
2. 打开本应用 → 首页「Shizuku 授权申请」→ 允许
3. （可选）安装 [Dhizuku](https://github.com/iamr0s/Dhizuku) 并激活为设备所有者，解锁设备控制页

## 关于

- 基于 Kotlin + Jetpack Compose，Material You 动态取色
- 界面参照 KernelSU 管理器风格
- 运行时零联网，不收集任何数据
- 全部特权操作可逆，卸载/冻结的系统应用可随时恢复

